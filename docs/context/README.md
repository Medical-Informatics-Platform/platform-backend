# Repository Context

This directory contains durable context for humans and AI coding agents working in this repository.

## Files
- `architecture.md`: system design and boundaries
- `module-index.md`: directory/module ownership
- `commands.md`: install, run, build, test, lint, typecheck
- `testing.md`: testing strategy and validation matrix
- `conventions.md`: coding patterns and repo norms
- `risk-register.md`: fragile, security-sensitive, or high-review areas
- `decision-log.md`: architectural decisions
- `code-review-checklist.md`: review checklist
- `ai-task-templates.md`: reusable prompts for agents

## How to use this context
Start with `AGENTS.md`, then read the files here that match the task. For code changes, check `architecture.md`, `module-index.md`, `commands.md`, `testing.md`, and `risk-register.md` before editing.
